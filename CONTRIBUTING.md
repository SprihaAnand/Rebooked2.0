# Contributing to Rebooked

We welcome contributions to Rebooked! By contributing, you help improve the platform for everyone. To get started, please read the guidelines below.

## How to Contribute

### Reporting Bugs

If you find a bug, please create an issue and include the following details:
- A clear and descriptive title
- Steps to reproduce the bug
- Expected and actual behavior
- Screenshots, if applicable
- Any other relevant information

### Suggesting Features

We welcome feature suggestions! Please create an issue and include:
- A clear and descriptive title
- A detailed description of the proposed feature
- Any relevant use cases or examples

### Code Contributions

1. **Fork the Repository**
   - Fork the repository by clicking the "Fork" button on the top right of the repository page.
